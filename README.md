# ⚡ OverClock

> Level up your finances through gamification.

OverClock is a gamified personal finance platform that transforms budgeting, saving, and expense tracking into an RPG-inspired experience. Users gain XP, level up, unlock achievements, and complete financial goals while managing their personal finances.

## 🚀 Live Demo

https://overclock-9.vercel.app/

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/<your-username>/<repo-name>.git
```

### Frontend

```bash
cd frontend

npm install

npm run dev
```

### Backend

```bash
cd backend

pip install -r requirements.txt

uvicorn app.main:app --reload
```
